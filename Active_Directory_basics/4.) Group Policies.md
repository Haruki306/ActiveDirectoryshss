<h1>Group Policies</h1>
<h3>In this project we had organized users, computers, and OUs. Now we will be deploying different policies for each OU individually. Windows manage policies through **Group Policy Object**.
</h3>
<h3>GPOs are simply a collection of settings that can be applied to OUs. They can contain policies aimed at either users or computers </h3>

<h1>Creating  GPOs for THM Inc.</h1>
<h3>What we will do with this task </h3>
<h4>1. Block non-IT users from accessing the Control Panel. </h4>
<h4>2. Make workstations and servers lock their screen automatically after 5 minutes of user inactivity to avoid people leaving their sessions exposed. </h4>

<h2>So how will we restrict access to control panel to only the users that are part of the IT department.</h2>
<h3>We will first need to create a new group policy called "Restrict Control Panel Access" in the **Group Policy Object** folder by right-clicking > New > then the name **Restrict Control Panel Access**</h3>
