<h1>Group Policies</h1>
<h3>In this project we had organized users, computers, and OUs. Now we will be deploying different policies for each OU individually. Windows manage policies through **Group Policy Object**.
</h3>
<h3>GPOs are simply a collection of settings that can be applied to OUs. They can contain policies aimed at either users or computers </h3>
